## 연령과 학년으로 선택하기

연령·학년·주제 연결은 편집상의 출발점이며 입학 연령 규정이나 인증된 교육과정 대응표가 아닙니다. 주별 입학 기준, 아이의 준비도, 학교 과정은 다릅니다. 미국 Grade나 영국 Key Stage를 호주 학년과 바로 같다고 볼 수 없습니다. Foundation의 명칭도 지역마다 다릅니다. Year 11–12는 실제 선택 과목과 주별 교육과정에 맞춰 선택하세요.

## 이용 방법

이 저장소의 본문은 한국어입니다. 외부 자료의 지원 언어는 각각 다르며, 이 안내가 한국어라고 해서 연결된 수업도 한국어인 것은 아닙니다. 해외 자료는 주제에 따라 골랐으며 호주 교육과정과 자동으로 일치한다고 보지 않습니다.

무료 범위 설명은 공식 출처를 근거로 합니다. 이번 확인에서 아동 계정을 만들거나 구독을 구매하거나 전체 과정을 이수하거나 모든 상호작용 기능을 실행하지는 않았습니다. 모델 하나를 선택하고, 아이가 설명한 뒤 결과를 확인하세요.
